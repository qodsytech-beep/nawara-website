# 🌿 Nawara Business Company — Website

> موقع شركة **نوارة** للاستيراد والتصدير وتجارة السلع الغذائية والخضر والفواكه.

![Nawara Logo](img%20primary/logo.jpg)

---

## 🔗 الموقع مباشر عبر GitHub Pages

> يمكن تفعيله من: **Settings → Pages → Branch: main → / (root)**

---

## 📁 هيكل المشروع

```
nawara/
├── index.html          ← الصفحة الرئيسية
├── img primary/        ← الصور الرئيسية والشعار
├── img sec/            ← معرض الصور (خضر، فواكه، موانئ، كتالوج سورينا)
└── video/              ← الفيديو التعريفي
```

## ✨ مميزات الموقع

- 🎨 تصميم **Premium Glassmorphism** مستوحى من ألوان شعار نوارة  
- 🌟 **Hero Slider** بـ 4 صور مع جسيمات متحركة (Canvas Particles)  
- 📊 **عدادات متحركة** للإحصائيات  
- 📋 **Timeline** لخطوات العمل  
- 🖼️ **معرض Masonry** مع Lightbox  
- 🎬 **مشغّل فيديو** منبثق  
- 📱 **تجاوب كامل** مع جميع الأجهزة  
- ⚡ تحميل سريع مع Preloader أنيق  

## 🏢 عن الشركة

شركة نوارة لتجارة السلع الغذائية والخضر والفواكه — رائدة في قطاعها بالجودة والالتزام والخبرة الوافية. منتجاتها تلبي المعايير العالمية للجودة والصحة وسلامة الغذاء.
